- `as`, `constraint`, `exception`, `external`, `mutable`, `of`, `open`, `private`, `rec` and `when` are contextual keywords: each is a keyword only where the grammar uses it and a name everywhere else, so `let open = dialog.open`, `{...dialog, open}`, `(~as) => as` and `exception => log(exception)` need no escape. An escaped spelling such as `\"open"` stays a name everywhere, so existing code keeps its meaning. The formatter prints these names bare, and escapes or parenthesizes them where the bare name would read as the keyword.
