- Build output moves from `lib/bs` and `lib/ocaml` into one flat `lib/rescript` directory per package, without copies of the sources or the generated JavaScript; the first build removes the old directories, and `lib/rescript` belongs in `.gitignore`. The empty `lib/bs/build.ninja` marker is gone; `lib/rescript/.sourcedirs.json` is rewritten when the project graph changes. `@rescript/runtime` ships its sources at the package root.
