# Checkpoint 10: frozen GenType parity

Status: validated for opt-in frozen lookup in projects that use GenType.
GenType requests use classic disk lookup; other requests in the same project
use frozen lookup. Frozen lookup remains opt-in until final promotion.

## Cause and request policy

Forcing frozen lookup on a GenType request changed imported TypeScript names
(`It as ILeaf_t` became `t as Leaf_t`) and could omit `Pair.gen.ts` when its
interface summary was read before the dependency CMI reached disk. GenType
resolves interface precedence and validates versioned dependency summaries
against disk artifacts. A project-wide classic fallback preserved output but
kept unrelated compile requests off the frozen path.

The embedded compiler now chooses lookup per request. Rewatch marks GenType
parse requests with `-bs-gentype`, so they retain the disk AST path; GenType
compile requests retain classic interface lookup. Non-GenType requests use
frozen lookup, including a dependency of a GenType package and a consumer of
one. When any package enables GenType, Rewatch publishes compiler artifacts to
disk before releasing dependents. The project metadata records that publication
policy and increments its format version, so switching policies invalidates
dependent caches.

## Parity gate

`frozen_gentype_parity.py` passed for three fixtures: recursive GenType
imports, a non-GenType dependency imported by a GenType package, and a
non-GenType consumer importing a GenType dependency. Each ran with
`REWATCH_BIN_ANNOT` unset, `0`, and `1`, under classic and frozen policies.
The gate checked clean, edit, restart, and policy-switch-back builds, complete
TypeScript/JavaScript/CMI/CMJ/GenType-summary file sets and hashes, request
traces, and identical interface-mismatch diagnostics. With annotations enabled,
it checked the annotation file set and semantic CMT/CMTI parity using
`cmt_compare`. The port integration suite also verifies the two mixed import
directions explicitly.

The final `make test`, `make test-gentype` with one and default compiler-domain
counts, `make test-analysis`, the OCaml Rewatch port suite, focused OUnit
(114 tests), and `make checkformat` passed. `make test` ran before the final
Rewatch publication change; the other final runs covered that change.

## Equal-work GenType build comparison

Five interleaved pairs used Linux 7.0.12-linuxkit on aarch64, `/tmp` on
overlayfs, the Dune `dev` profile, four compiler domains, and
`REWATCH_BIN_ANNOT=0`. Before every build, the runner removed generated `lib`
directories for Belt, the React dependency, and the TypeScript React example.
Each sample compiled 141 modules and produced the same digest for 89 generated
TypeScript and JavaScript files. Earlier runs that did not clear all three
package outputs had unequal compiler work and are excluded.

| Policy | Median wall | Median CPU | Median peak RSS |
| --- | ---: | ---: | ---: |
| Classic lookup | 996.51 ms | 1194.76 ms | 87,768 KiB |
| Frozen request split | 960.13 ms | 1143.13 ms | 103,612 KiB |

The frozen policy reduced median wall time by 3.6% and raised median sampled
peak RSS by 18%. The memory increase is below the performance gate's 125%
limit, but it remains a cost to monitor at promotion. Raw samples are in
`/tmp/rewatch-step10-large-benchmark-equal/samples.csv` in this workspace.
