# Checkpoint 12: core promotion gate

Status: local Linux validation passed; promotion is pending macOS and Windows
results for these commits. The branch has not been pushed.

## Default and retained paths

OCaml Rewatch already creates sessions with frozen lookup enabled and turns on
owned AST and compiler-artifact handoff. Checkpoints 7–11 validated those
defaults, including mixed GenType packages. Standalone `bsc` keeps its normal
disk-reader default. No further default toggle is needed for this branch.

The remaining alternate paths serve active contracts, so none can safely be
removed as superseded: GenType requests need classic lookup and disk AST/CMI
publication; restarted builds and cache eviction need persistent artifacts;
prebuilt GenType dependencies need the legacy CMT reader; editor consumers
need annotation files and compatibility copies when enabled; and existing
external PPXs need the frozen AST 0 protocol. The opt-out settings remain
useful for comparing the classic compiler path and diagnosing regressions.

target replacement case. The test created its temporary replacement in

The fixture now creates the temporary file beside the target. The focused
suite then passed with 1, 4, and 12 domains. The failed run remains recorded
at `/tmp/rewatch-step12-close-port-4-repro.log`; the passing corrected runs
are in `/tmp/rewatch-step12-close-port-*-atomic.log`.
